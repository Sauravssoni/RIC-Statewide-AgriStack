# Field Channel Positioning

The challenge requires an offline-first farmer-facing mobile application. RAJ-AGRISETU X therefore treats the farmer PWA as the mandatory digital channel and SUTRA-ID Edge as an optional last-mile extension.

## Channel hierarchy
1. **Farmer PWA** — installable, offline-first, self-verification, local queue, consent, scheme pre-check.
2. **Assisted service** — same workflow operated with the farmer through eMitra/CSC/FPO/Krishi Sakhi/department camps, subject to approved operating policy.
3. **SUTRA-ID Edge** — voice-first, low-connectivity and field evidence channel for cases where personal smartphone/digital literacy is a barrier.

## SUTRA proof position
The Syntheon prototype has demonstrated standalone edge operation, touch/voice workflow, evidence capture, human confirmation and portable signed receipt patterns. In this project, SUTRA does not become an authoritative identity or land-record device; it is an execution endpoint for the same governed transaction contracts used by the farmer PWA.

## BHASHINI position
BHASHINI is the preferred production language-AI rail for authorized ASR/TTS/translation. Browser speech synthesis in the evaluator PWA is only a local fallback so the demo remains functional without pretending to have a live privileged BHASHINI connection.
