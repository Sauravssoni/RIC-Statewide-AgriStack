# 90-Day Pilot Acceptance Criteria

## Phase 1 — Days 0–15: discovery and controls
- Authoritative-source inventory and ownership matrix agreed.
- Pilot districts/blocks selected with contrasting connectivity/land-mutation conditions.
- Raj Sewa Dwaar/UFSI/Jan Aadhaar/RoR interface contracts documented.
- Data-protection, access-control and synthetic-test-data plan approved.

## Phase 2 — Days 15–35: trust core
- Farmer-land relationship model implemented.
- CARE ingests approved mutation/event inputs and produces traceable review cases.
- SahmatiOS purpose-policy receipts and audit events functioning.
- Contract/sandbox adapters return conformance results without claiming unauthorized production access.

## Phase 3 — Days 35–55: channels
- Officer MIS supports State and district operational scope.
- Farmer PWA installs, opens offline, captures transaction and preserves queue across reload.
- Assisted workflow and SUTRA-ID Edge field pattern use the same transaction contract.

## Phase 4 — Days 55–75: field validation
- Offline transaction sync success measured across pilot field conditions.
- CARE discrepancy resolution workflow exercised with authorized pilot personnel.
- Accessibility/Hindi/BHASHINI-assisted journeys tested.
- Performance, error handling and reconciliation observability tested.

## Phase 5 — Days 75–90: UAT, hardening and handover
- Security/UAT defects closed or formally accepted.
- API documentation, operating runbook, audit/export design and support procedures handed over.
- Statewide capacity and phased scale-out model delivered.

## Recommended pilot KPIs
- median mutation-to-CARE detection time
- median CARE case resolution time
- land-link freshness rate
- successful offline transaction acknowledgement rate
- purpose-consent completeness/revocation rate
- reduction in repeated farmer data/document submission
- workflows completable without personal smartphone
- integration/API error rate and reconciliation retry rate

No KPI target should be represented as achieved before pilot measurement; evaluator prototype numbers are synthetic unless marked verified baseline.
