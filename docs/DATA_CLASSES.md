# Data Classes Used in the Prototype

- **VERIFIED BASELINE** — aggregate value reproduced from a cited Government source, with source date/as-of.
- **SYNTHETIC OPERATIONAL KPI** — deterministic evaluator value used to exercise dashboards and queues; never represented as live Rajasthan telemetry.
- **SYNTHETIC PERSON/CASE** — fictional farmer, Farmer ID, parcel, receipt or case record.
- **PUBLIC REFERENCE** — information available from an official/public source but not a privileged production integration.
- **SANDBOX** — interface/behavior intended to match a provided test or sandbox environment.
- **CONTRACT READY** — adapter architecture prepared; production credentials/approval not yet available.
- **LIVE PROTOTYPE** — code/device behavior that can be executed in the evaluator environment without claiming Government source authority.

These labels are part of the product's trust model and should remain visible in all submission surfaces.
