## Data-class rule

Verified aggregate baselines are never blended with synthetic operational KPIs. Every FarmGraph integrity score, district score, CARE backlog, consent rate or offline-sync metric is explicitly evaluator-demo data until a Department-authorized operational source is connected.

## Reproducibility note

The ledger deliberately uses dated/as-of values from cited official pages rather than treating a live dashboard as immutable. If an official source page is subsequently refreshed, the source date/as-of above remains the governing value for the submitted evidence pack.
