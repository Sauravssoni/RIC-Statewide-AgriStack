# RAJ-AGRISETU X — Prototype → Production Contract

RAJ-AGRISETU X is intentionally presented as an **interactive evaluator prototype**, not as a claim that Syntheon already operates Rajasthan's authoritative AgriStack production environment.

## What is materially proven in the prototype

- State Mission Control interaction model.
- FarmGraph AI temporal relationship model and explainable conflict detection.
- CARE source-state separation and human-authority decision receipts.
- Installable Hindi-first Farmer PWA.
- Transactional offline queue → reconnect acknowledgement → CARE revalidation semantics.
- Purpose/scope/duration consent policy receipts.
- Deterministic, non-statutory Scheme Compiler trace.
- Role-aware Government operating workflow patterns.
- Explicit integration truth states.
- 41-district statewide operations model using synthetic evaluator metrics plus verified aggregate baselines.
- SUTRA-ID Edge as an optional low-connectivity / voice-first field execution rail.

## What the proposed 90-day engagement refines and productionizes

The funded engagement does **not** merely redesign the prototype. It converts the proven interaction and governance contracts into a Department-operational production core by adding:

1. Department-approved AgriStack/UFSI, Jan Aadhaar, e-Dharti/DILRMP, Raj Sewa Dwaar, Raj SSO, Rajdharaa/LGD, RajKisan and other authorized connectors.
2. Current authoritative administrative/spatial geometry and production GIS services.
3. Department-approved hosting, identity, secrets, logging, security and audit controls.
4. DPIA/privacy review, threat modelling, penetration/security testing and UAT.
5. Field validation across contrasting Rajasthan connectivity, irrigation and mutation conditions.
6. Accessibility and language hardening with authorized BHASHINI services where available.
7. Observability, retry/reconciliation controls, operational SLAs and State/district runbooks.
8. Training, handover and a phased statewide scale blueprint.

## Product philosophy

**Prototype today:** prove the hard workflow and governance decisions.

**90-day production core:** connect authorized systems, validate in the field and harden for Government operation.

**Statewide scale:** expand only after measured pilot acceptance criteria are met.

This distinction is deliberate. It prevents demo theatre while showing Rajasthan that Syntheon has already de-risked the core architecture before requesting implementation funding.
